# 말랑 인형뽑기

브라우저에서 바로 즐기는 캐주얼 인형뽑기 게임입니다. 오리지널 캐릭터 14종을 캔버스에 직접 그리며, 외부 이미지는 쓰지 않습니다.

- [옆에서 보기](https://sketchkim-hub.github.io/claw-game/) — 옆면 시점, 집게를 좌우로 움직여 인형을 집습니다.
- [위에서 보기](https://sketchkim-hub.github.io/claw-game/top/) — 위에서 내려다보는 시점, 방향키(또는 십자 버튼)로 집게를 옮긴 뒤 출구 구멍으로 가져갑니다.

## 조작
- 옆면: ◀ ▶ 또는 ← →, 집기는 스페이스 / **집기!**
- 위: 십자 버튼 또는 방향키, 집기는 스페이스 / **집기!**
- 기회 4번, 한 번에 15초
- ✨ 별똥이는 50점 (희귀)

## 캐릭터
콩떡이, 말랑곰, 솜솜이, 꿀벌콩, 단무다, 도토리, 감자펭, 호떡포, 딸기냥, 밤송이, 개굴몽, 구름고래, 달마우, 별똥이
